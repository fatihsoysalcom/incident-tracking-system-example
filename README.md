# Incident Tracking System Example

This example demonstrates a basic incident management system that tracks service outages. It shows how to create, update, and resolve incidents, ensuring that no critical events are forgotten. The system maintains a historical record of all incidents, addressing the common problem of incident management tools 'forgetting' past events or current states.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
